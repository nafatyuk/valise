Privacy policy

Effective November 11, 2026

Valise is a personal tool used by a single person, its developer, with that person's own Google accounts. Nobody else is invited or able to use it.

Data accessed

With the owner's consent, the tool uses the Gmail API (gmail.modify) to read the owner's messages, threads, and labels, and to change labels on the owner's threads.

How data is used

Data is used only to carry out what the owner asks for in the moment, such as finding an email, summarizing a thread, or archiving or labeling it. When the owner asks their AI assistant about their mail, the relevant mail content is passed to that assistant to answer the request, under the terms the owner has with that assistant's provider.

Storage

The tool has no server. It runs entirely on the owner's Mac. Google sign-in tokens are kept in the macOS Keychain. Mail is not copied into any database or service operated by this project.

Sharing

Data is not sold, not used for advertising, and not shared with anyone other than as described above. Humans other than the owner do not read it.

Google API Services User Data Policy

Valise's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions, which also invalidates the tokens kept on the Mac.

Contact

Questions can be raised through this project's GitHub issues.
